# CAS IQ

CAS IQ is an intelligent event-processing platform for Central Alarm Stations, designed to automate repetitive alarm workflows.

## Project Goal

The goal of CAS IQ is to reduce repetitive manual work by processing simulated alarm events and automatically determining the appropriate workflow.

## Planned Features

- Process simulated alarm signals
- Apply rule-based automation
- Prioritize events by type and severity
- Record event history and operator actions
- Generate basic analytics
- Add AI-assisted recommendations in future versions

## Development Roadmap

### Phase 1
Build a basic Python program that receives and displays simulated alarm events.

### Phase 2
Add rules that automatically classify and process low-priority events.

### Phase 3
Store event history and generate reports.

### Phase 4
Add analytics and AI-assisted decision support.

## Technologies

- Python
- Git and GitHub
